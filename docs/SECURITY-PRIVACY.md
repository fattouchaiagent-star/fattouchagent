# FATTOUCH AI — الأمان والخصوصية

## 1. نطاق البيانات الحساسة

- السير الذاتية والهوية وبيانات الاتصال.
- الشهادات والعقود والوثائق الحكومية.
- البريد والطلبات الوظيفية.
- الموقع والتفضيلات الصحية أو المالية المحتملة.
- رموز الدخول أو بيانات الدفع إن ظهرت في أي تكامل.

## 2. مبادئ الحماية

- جمع الحد الأدنى اللازم.
- غرض واضح لكل استخدام.
- موافقة منفصلة للتخزين والمشاركة والتدريب.
- تشفير أثناء النقل والتخزين.
- عزل بيانات المستخدمين.
- صلاحيات أقل امتياز.
- حذف قابل للتحقق.
- عدم تسجيل الأسرار أو محتوى الملفات في سجلات التشغيل.

## 3. دورة حياة الملف

1. رفع آمن.
2. فحص النوع والحجم والبرمجيات الضارة.
3. تخزين مع معرف غير قابل للتخمين.
4. معالجة ضمن صلاحية محددة.
5. عرض البيانات المستخرجة للمراجعة.
6. استخدام فقط ضمن الغرض الموافق عليه.
7. حذف الأصل والمشتقات والفهارس عند الطلب.
8. تسجيل نتيجة الحذف دون تسجيل المحتوى.

## 4. الموافقات

يجب تمييز:

- موافقة تحليل الملف.
- موافقة حفظ الملف.
- موافقة استخدامه لتحسين الخدمة.
- موافقة مشاركته مع جهة خارجية.
- موافقة تنفيذ الإجراء.

لا يجوز اعتبار استخدام الخدمة موافقة شاملة على كل ما سبق.

## 5. أمن الوكلاء والأدوات

- محتوى صفحات الويب غير موثوق ولا يملك صلاحية تغيير تعليمات النظام.
- فصل تعليمات المستخدم عن تعليمات الأدوات.
- قوائم نطاقات مسموحة للإجراءات الخارجية.
- تحقق من الوجهة قبل الإرسال.
- منع حقن التعليمات من المستندات أو صفحات الويب.
- حدود زمنية وعددية لكل مهمة.
- تسجيل كل استدعاء أداة حساس.

## 6. الإرسال الخارجي

قبل الإرسال يعرض النظام:

- المحتوى كاملًا أو ملخصًا قابلًا للفتح.
- الجهة والرابط.
- الملفات المرفقة.
- البيانات الشخصية.
- التكلفة أو الأثر.
- مدة صلاحية الموافقة.

## 7. الاستجابة للحوادث

- اكتشاف وعزل.
- إيقاف الأداة المتأثرة.
- تحديد البيانات والنطاق.
- حفظ الأدلة دون توسيع الوصول.
- إبلاغ المسؤولين والمستخدمين حسب الالتزام القانوني.
- تدوين الإجراء التصحيحي.

## 8. السلامة في المجالات الحساسة

### الصحة
معلومات عامة، مصادر موثوقة، لا تشخيص، لا وصفة، تنبيه للطوارئ.

### القانون
شرح عام، إحالة إلى جهة مختصة، لا ضمان للنتيجة.

### المال
لا وعود بعائد، لا تنفيذ تحويلات دون تكامل آمن وموافقة مستقلة.

### الوظائف
لا ضمان توظيف، ولا مشاركة CV مع صاحب عمل دون إذن.

## 9. اختبارات إلزامية قبل الإطلاق

- اختبار عزل حسابين.
- اختبار حذف كامل.
- اختبار حقن من ملف PDF وصفحة ويب.
- اختبار إرسال دون موافقة.
- اختبار تسريب البيانات في السجلات.
- اختبار روابط ومصادر ضارة.
- اختبار صلاحيات المراجع والمدير.
- اختبار استعادة آمنة من النسخ الاحتياطية.

## 10. الوثائق القانونية المطلوبة

قبل الإطلاق العام يجب إعدادها بمراجعة قانونية مناسبة:

- سياسة الخصوصية.
- شروط الاستخدام.
- سياسة حذف واحتفاظ.
- سياسة المحتوى المحظور.
- سياسة استخدام المصادر.
- إخلاء مسؤولية للمجالات الحساسة.
