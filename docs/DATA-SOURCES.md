# FATTOUCH AI — مصادر البيانات والبحث

## 1. سياسة المصادر

ترتيب الأولوية:

1. مصدر حكومي أو رسمي.
2. الموقع الرسمي للجهة أو الشركة.
3. مزود بيانات معروف ومرخص.
4. مؤسسة مهنية أو إعلام موثوق.
5. دليل عام أو محتوى مستخدمين، مع وسمه بوضوح.

لا تُستخدم منشورات مجهولة كمصدر وحيد لمعلومة مهمة.

## 2. سجل المصدر

لكل مصدر:

- اسم المصدر.
- الرابط الأساسي.
- نوعه ومالكه.
- المجال.
- تاريخ الإضافة وآخر فحص.
- تكرار التحديث المتوقع.
- طريقة الوصول والقيود.
- حقوق الاستخدام.
- درجة الثقة.
- مسؤول المراجعة.

## 3. المجالات الأولية

### الوظائف
- صفحات الوظائف الرسمية للشركات.
- منصات التوظيف التي تسمح بالوصول أو التعاون.
- صفحات الجامعات ومراكز التوظيف.
- مصادر الوظائف عن بُعد التي تقبل المقيمين في لبنان.

### السياحة
- وزارة السياحة والبلديات عند توفر المعلومات.
- المواقع الرسمية للمعالم والفنادق.
- مزودو الخرائط والطقس.
- مواقع الحجز أو الشركاء المسموحون.

### الخدمات المحلية
- مواقع الوزارات والبلديات.
- أدلة المؤسسات الرسمية.
- مواقع الشركات وملفاتها الموثقة.
- مصادر الخرائط المرخصة.

## 4. قواعد التحديث

- البيانات الحساسة للوقت تحتاج تاريخ وصول واضح.
- ساعات العمل والأسعار والوظائف تفحص دوريًا.
- المصدر المنقطع لا يحذف فورًا؛ يوسم بأنه غير متاح.
- الإعلان المنتهي لا يعرض ضمن النتائج النشطة.
- لا نخلط بين تاريخ نشر الصفحة وتاريخ آخر تحديث للمحتوى.

## 5. استخراج البيانات

لكل معلومة مستخرجة تحفظ:

- القيمة.
- نوع الحقل.
- المصدر.
- موضعها في الصفحة أو المستند.
- وقت الاستخراج.
- وقت التحقق.
- درجة الثقة.
- حالة التعارض.

## 6. التعامل مع التعارض

عند تعارض مصدرين:

1. نفضل المصدر الأولي الأحدث.
2. نتحقق من اختلاف تعريف المعلومة.
3. نعرض التعارض إذا لم يمكن حسمه.
4. لا نحسب متوسطًا لمعلومة لا يصح متوسطها.
5. نتيح للمستخدم فتح المصدرين.

## 7. حقوق الاستخدام

- لا تُجمع بيانات مخالفة لشروط المصدر.
- تحترم robots.txt والقيود التقنية والقانونية.
- لا يُعاد نشر محتوى محمي كاملًا عند عدم الترخيص.
- تعرض مقتطفات ضرورية مع رابط المصدر.
- التكاملات الرسمية مفضلة على الكشط.

## 8. بلاغات المستخدمين

يستطيع المستخدم الإبلاغ عن:

- عنوان خاطئ.
- هاتف غير صالح.
- ساعات عمل قديمة.
- وظيفة منتهية.
- سعر غير صحيح.
- مصدر غير مناسب.

لا يتحول البلاغ إلى حقيقة تلقائيًا؛ يدخل في طابور مراجعة.

## 9. معايير قبول البحث

- كل نتيجة محلية متغيرة لها مصدر أو وسم "غير متحقق".
- لا تتكرر المؤسسة بأشكال كتابة مختلفة دون دمج.
- الروابط قابلة للفتح أو يوسم المصدر بالفشل.
- يستبعد النظام النتائج التي تجاوزت مدة الصلاحية المحددة للمجال.
- يستطيع المراجع معرفة كيف وصلت القيمة إلى قاعدة البيانات.
