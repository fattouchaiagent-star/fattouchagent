# FATTOUCH AI — المتطلبات التقنية المبدئية

> هذا المستند يحدد ما يجب أن يحققه النظام قبل اختيار إطار العمل النهائي. لا يحتوي على كود.

## 1. طبقات النظام

1. **واجهة العميل:** محادثة، رفع ملفات، حالة المهمة، النتائج، المصادر، الموافقات.
2. **طبقة الهوية:** حسابات، جلسات، صلاحيات، موافقات.
3. **منسق المهام:** يحول الطلب إلى خطة وخطوات قابلة للتنفيذ.
4. **بوابة الأدوات:** سجل أدوات، مخططات إدخال/إخراج، صلاحيات، مهلات.
5. **طبقة البحث والاسترجاع:** بحث نصي ودلالي، إعادة ترتيب، توثيق.
6. **طبقة المستندات:** تخزين، فحص، OCR، استخراج، تصنيف وحذف.
7. **طبقة البيانات المحلية:** كيانات لبنان، مواقع، وظائف، مزودو خدمات، مصادر.
8. **طبقة الإجراءات:** بريد، نماذج، حجوزات مستقبلية، مع بوابة موافقة.
9. **المراقبة والتقييم:** سجلات منقحة، مقاييس، تقييم جودة ومخاطر.

## 2. عقد المهمة

كل مهمة يجب أن تحتوي منطقيًا على:

- معرف المهمة.
- المستخدم والطلب الأصلي.
- النية والمجال ومستوى الخطر.
- الخطة والإصدار.
- الخطوات وحالاتها.
- الأدوات والمدخلات المنقحة.
- المصادر والاستشهادات.
- الموافقات المطلوبة والممنوحة.
- النتيجة النهائية والقيود.
- أحداث التدقيق.

## 3. نظام الأدوات

كل أداة تسجل:

- الاسم والوصف.
- نوع الخطر.
- مخطط المدخلات والمخرجات.
- النطاقات المسموحة.
- المهلة وإعادة المحاولة.
- هل هي قراءة فقط أم لها أثر خارجي.
- البيانات التي قد تخرج منها.
- طريقة التحقق من نجاحها.

لا يسمح للمنسق باستدعاء أداة غير مسجلة أو إرسال مدخلات خارج مخططها.

## 4. بوابة الموافقات

- قراءة ملف خاص: موافقة استخدام واضحة.
- مشاركة ملف: عرض الحقول والجهة.
- إرسال بريد أو طلب: معاينة نهائية.
- حجز أو دفع: تأكيد مستقل مع التكلفة.
- عملية غير قابلة للعكس: تأكيد إضافي وشرح الأثر.
- يمنع اعتماد موافقة قديمة إذا تغيرت الجهة أو البيانات أو الأثر.

## 5. البحث والاسترجاع

المطلوب:

- فهرسة مصادر مسجلة.
- تخزين النص مع الرابط والعنوان والتاريخ.
- فهرسة دلالية للنصوص الطويلة.
- بحث بالكلمات والأسماء العربية واللاتينية.
- دعم اختلافات كتابة أسماء المناطق.
- إعادة ترتيب بحسب الصلة والموثوقية والحداثة.
- ربط كل فقرة مسترجعة بالمصدر.
- عدم إسناد معلومة إلى مصدر لم يحتوها.

## 6. المستندات

- فحص امتداد وحجم الملف.
- فحص برمجيات ضارة قبل المعالجة.
- تشفير التخزين.
- استخراج النص مع صفحة/موضع المصدر.
- فصل النص المستخرج عن الملف الأصلي.
- حذف المتعلقات والفهارس عند الحذف.
- منع الملف من أن يصبح تعليمات نظام غير موثوقة.

## 7. الجودة والتقييم

إنشاء مجموعة تقييم لبنانية تشمل:

- لهجات وصيغ عربية مختلفة.
- أسماء مناطق ومؤسسات.
- أسئلة سياحية واقعية.
- وظائف وسير ذاتية منزوعة الهوية.
- مصادر متعارضة أو قديمة.
- محاولات طلب بيانات حساسة.
- طلبات تنفيذ غير مصرح بها.

المقاييس:

- دقة استخراج المستند.
- صحة الاستشهاد.
- حداثة النتيجة.
- نسبة الادعاءات غير المدعومة.
- نجاح تصنيف الخطر.
- نسبة الموافقات الصحيحة.
- زمن إكمال المهمة.
- تكلفة المهمة.
- رضا المستخدم.

## 8. الاعتمادية

- مهام خلفية قابلة للاستئناف.
- معرفات idempotency للإجراءات.
- مهلات لكل أداة.
- حواجز تكلفة وزمن.
- fallback عند فشل المصدر.
- حفظ النتيجة الجزئية.
- عدم إعادة الإرسال تلقائيًا لإجراء خارجي غير idempotent.

## 9. متطلبات التشغيل

- بيئات منفصلة للتطوير والاختبار والإنتاج.
- الأسرار في مدير أسرار.
- ترحيلات قاعدة بيانات قابلة للتراجع.
- نسخ احتياطية واختبار استعادة.
- مراقبة الأخطاء والبطء والإنفاق.
- تنبيهات للحالات عالية الخطورة.

## 10. جاهزية البرمجة

لا يبدأ التنفيذ قبل اعتماد:

- نموذج البيانات.
- عقد المهمة والأدوات.
- مصادر MVP وسياساتها.
- مصفوفة الموافقات.
- سياسة الاحتفاظ والحذف.
- مجموعة التقييم الأولى.
- معايير القبول لكل قصة مستخدم.
