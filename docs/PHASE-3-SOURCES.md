# المرحلة الثالثة — سجل المصادر والبحث

## الحالة الحالية

بدأت المرحلة الثالثة بسجل مصادر صريح. يعرض `GET /api/sources` المصادر المسجلة مع حالة `not_connected` إلى أن يتم بناء موصل حقيقي ومراجعته. لا يجوز اعتبار سجل المصدر نتيجة بحث أو عرض وظائف حقيقية.

## عقد المصدر

كل مصدر يحتوي على:

- `id`, `name`, `url`
- `coverage`, `priority`
- `status`: `not_connected` أو حالة موصل معتمدة لاحقًا
- `fetched`: هل تم الجلب فعليًا
- `lastCheckedAt`: آخر فحص فعلي، ويبقى `null` قبل الموصل
- `confidence`: درجة الثقة بعد التحقق، وتبقى `null` قبل التحقق

## قواعد الموصلات القادمة

1. احترام شروط الاستخدام وrobots.txt والقيود القانونية.
2. عدم عرض نتيجة بلا رابط مصدر وتاريخ جلب.
3. وسم المصدر غير المتاح بدل اختلاق نتائج.
4. إزالة التكرار بالعنوان والرابط والجهة قبل العرض.
5. حفظ مقتطف ضروري فقط، لا نسخ المحتوى الكامل المحمي.
6. فصل بيانات الموصل عن بيانات الإعلان المحلي.
7. اختبار التعارض بين مصدرين قبل اعتماد النتيجة.

## بوابة المرحلة

لا نفعّل نتائج وظائف أو معلومات محلية حقيقية للمستخدمين قبل وجود موصل واحد على الأقل، واختبار مصدره، وإظهار الرابط وحالة التحقق وتاريخ الجلب داخل بطاقة النتيجة.
