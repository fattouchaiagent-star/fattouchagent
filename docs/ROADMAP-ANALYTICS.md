# FATTOUCH AI — خارطة الطريق والتحليلات

## المرحلة 0: التوثيق والتحقق

- اعتماد PRD.
- مقابلات مع مستخدمين لبنانيين.
- تحديد مصادر MVP وشروط استخدامها.
- بناء مجموعة تقييم عربية لبنانية.
- مراجعة قانونية أولية للخصوصية والمصادر.
- تصميم prototype لتدفق المهمة والموافقة.

**بوابة الانتقال:** قصص المستخدم ومعايير القبول ومصادر البداية معتمدة.

## المرحلة 1: MVP محدود

- محادثة عربية/إنجليزية/فرنسية.
- تسجيل وحساب ضيف.
- رفع وتحليل CV.
- بحث وظائف من مصادر محددة.
- مخطط سياحي دون حجز تلقائي.
- بحث محلي موثق.
- مصادر ومراحل تقدم وموافقات.
- حذف وتصدير أساسي.

**بوابة الانتقال:** تحقق الجودة والسلامة وقابلية الاستخدام.

## المرحلة 2: تنفيذ محدود

- تجهيز رسائل التقديم.
- تعبئة نماذج مع مراجعة.
- تكاملات بريد مع موافقة.
- حفظ تفضيلات المستخدم.
- تنبيهات للوظائف وتغيّر المعلومات.
- لوحة مراجعة للمصادر والبلاغات.

## المرحلة 3: شبكة خدمات محلية

- شراكات مع شركات ومؤسسات سياحية.
- بيانات تجارية محدثة.
- حجز عبر مزودين معتمدين.
- حسابات للشركات.
- واجهة API للشركاء.

## المقاييس الأساسية

### التفعيل
- نسبة المستخدمين الذين يرسلون أول طلب.
- زمن الوصول لأول نتيجة مفيدة.
- نسبة رفع ملف أو بدء مهمة مركبة.

### الجودة
- تقييم المستخدم للنتيجة.
- نسبة فتح المصادر.
- نسبة تصحيح النتائج.
- نسبة الادعاءات المدعومة.
- نسبة الوظائف المكررة أو المنتهية.

### التنفيذ
- نسبة المهام المكتملة.
- نسبة الموافقات.
- نسبة الإلغاء قبل الإرسال.
- نجاح الإجراءات الخارجية بعد التحقق.

### التشغيل
- زمن الاستجابة.
- زمن الأدوات.
- التكلفة لكل مهمة.
- الأخطاء حسب المصدر والأداة.
- معدل إعادة المحاولة.

### الثقة والسلامة
- بلاغات معلومات خاطئة.
- حوادث الخصوصية.
- محاولات تجاوز الموافقة.
- إجابات عالية المخاطر أُوقفت أو أحيلت لمختص.

## قواعد القياس

- لا تسجل محتوى المستند في التحليلات.
- استخدم معرفات مجهولة أو مستعارة.
- لا تعتبر نجاح استدعاء الأداة نجاح المهمة دون تحقق.
- تفصل مقاييس الضيف عن المستخدم المسجل.
- تحفظ نسخة من تعريف كل مقياس.

## قرار الجاهزية للإطلاق

يجب تحقق كل ما يلي:

- اختبار قبول لكل FR أساسي.
- لا إجراءات خارجية بلا موافقة.
- مسار حذف ملف موثق ومختبر.
- مصادر أولية كافية للمجالات الثلاثة.
- لوحة أخطاء ومصادر متوقفة.
- تجربة عربية RTL قابلة للاستخدام.
- مراجعة أمان وخصوصية.
- خطة دعم للمستخدمين وإدارة البلاغات.
