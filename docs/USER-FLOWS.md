# FATTOUCH AI — تدفقات المستخدم

## 1. التدفق العام للمهمة

1. يكتب المستخدم طلبًا أو يرفع ملفًا.
2. يحدد النظام اللغة والنية والمعلومات الناقصة.
3. يعرض خطة قصيرة قابلة للتعديل.
4. يختار الأدوات المسموحة للمهمة.
5. ينفذ البحث أو التحليل على مراحل.
6. يعرض حالة كل خطوة والمصادر والنتائج الجزئية.
7. يتحقق من التكرار والحداثة والتعارضات.
8. يقدم النتيجة والتوصيات والخيارات التالية.
9. يطلب موافقة قبل الإجراء الخارجي.
10. ينفذ الإجراء ويسجل النتيجة أو الفشل بوضوح.

## 2. تدفق تحليل السيرة الذاتية

### المدخلات
- PDF أو DOCX أو صورة أو نص.
- المدينة أو منطقة العمل.
- نوع الوظيفة.
- تفضيل دوام/عن بُعد.
- الحد الأدنى للراتب، اختياري.

### الخطوات

1. الموافقة على قراءة الملف.
2. استخراج الاسم والخبرة والتعليم والمهارات واللغات.
3. عرض البيانات المستخرجة للتصحيح.
4. إنشاء ملف مهني قابل للبحث.
5. البحث في مصادر الوظائف المسموحة.
6. إزالة الوظائف المكررة والمنتهية.
7. حساب درجة الملاءمة مع تفسيرها.
8. عرض أفضل النتائج مع المصدر والتاريخ.
9. إنشاء نسخة CV ورسالة مخصصة، دون استبدال الأصل.
10. تجهيز طلبات التقديم.
11. مراجعة المستخدم.
12. الإرسال فقط بعد الموافقة لكل جهة أو لمجموعة محددة.

### شروط القبول
- لا تُرسل أي معلومات قبل الموافقة.
- يستطيع المستخدم حذف السيرة الذاتية.
- كل وظيفة تعرض رابطًا أصليًا.
- يظهر سبب التوصية، وليس النسبة وحدها.

## 3. تدفق التخطيط السياحي

1. تحديد الوجهة أو طلب اقتراح.
2. جمع عدد الأشخاص والمدة والميزانية والتاريخ والتفضيلات.
3. طلب المعلومات الناقصة فقط إذا أثرت في النتيجة.
4. فحص الطقس، الطريق، ساعات العمل، والأسعار المتاحة.
5. اقتراح خيارات متعددة: اقتصادي، متوازن، مميز.
6. بناء جدول زمني قابل للتعديل.
7. عرض التكلفة التقديرية وما هو غير مؤكد.
8. فتح روابط الحجز أو تنفيذ الحجز عبر تكامل معتمد بعد التأكيد.

## 4. تدفق البحث المحلي

1. فهم الكيان أو الخدمة والمنطقة.
2. البحث في المصادر الأولية ثم الثانوية.
3. دمج السجلات المتشابهة.
4. التحقق من العنوان والهاتف وساعات العمل.
5. عرض النتائج على خريطة أو قائمة.
6. إظهار آخر تحقق ومصدر كل حقل متغير.
7. تمكين المستخدم من الإبلاغ عن خطأ.

## 5. تدفق سؤال عالي المخاطر

يشمل الصحة والقانون والمال والسلامة.

1. تصنيف السؤال.
2. وضع تنبيه واضح بأن الرد معلومات عامة.
3. الاعتماد على مصادر رسمية أو مهنية.
4. عدم إعطاء تشخيص أو ضمان أو قرار نهائي.
5. اقتراح التواصل مع مختص أو جهة رسمية عند الحاجة.
6. تسجيل سبب رفض أي إجراء خطر.

## 6. الحالات والحالات الانتقالية

- `received`: تم استلام الطلب.
- `clarifying`: نحتاج معلومة.
- `planning`: بناء خطة التنفيذ.
- `researching`: استخدام مصادر وأدوات.
- `verifying`: التحقق والمقارنة.
- `awaiting_approval`: انتظار موافقة.
- `executing`: تنفيذ إجراء مصرح.
- `completed`: اكتملت المهمة.
- `partial`: اكتملت جزئيًا مع توضيح النقص.
- `failed`: فشلت مع سبب وخيار إعادة المحاولة.
- `cancelled`: ألغى المستخدم المهمة.
